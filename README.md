# 🌤️ Weather App

A simple weather application built using Flask and the OpenWeatherMap API.

## Features

- Search weather by city
- Displays:
  - Temperature
  - Feels Like
  - Humidity
  - Wind Speed
  - Weather Description
  - Weather Icon
- Error handling for invalid cities

## Tech Stack

- Python
- Flask
- HTML
- CSS
- OpenWeatherMap API
